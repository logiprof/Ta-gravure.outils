Tous les outils de ta-gravure.art réunis en une seule extension modulaire, avec mises à jour automatiques depuis GitHub.

== Description ==

Modules (chacun s'active séparément et a ses propres réglages, menu « Ta-gravure ») :

* Charte graphique – couleurs et styles de la page d'accueil sur tout le site.
* Formulaire de contact – code court [tg_contact], « Demandes clients » avec statuts et notes.
* E-mails et factures – e-mails WooCommerce et factures PDF aux couleurs du site.
* Personnalisation à graver – champs de personnalisation par produit (onglet « Personnalisation »).
* Prix dégressifs – paliers par produit ou catégorie, code court [prix_degressifs].
* Partage social & SEO – Open Graph, Twitter/X, robots.txt et plan du site.

== Installation ==

1. Extensions › Ajouter › Téléverser une extension › ta-gravure-outils.zip › Installer › Activer.
2. Les anciennes extensions séparées sont désactivées automatiquement. Leurs réglages et données sont repris.
3. Vous pouvez ensuite supprimer les anciennes extensions (Extensions › Inactives).

== Mises à jour ==

L'extension vérifie GitHub toutes les 6 heures et installe seule chaque nouvelle version
(réglage : Ta-gravure › Mises à jour).
